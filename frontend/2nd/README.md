# 2단계 — ON/OFF 버튼 배치하기

## 학습 목표
HTML `<button>` 요소와 CSS 스타일을 익힙니다.

## 실습 파일
- [index.html](index.html)

## 실행 방법
- 1~4단계: `index.html`을 브라우저에서 직접 열어도 됩니다.
- 5단계: Python Backend와 Nginx를 모두 실행한 다음 `http://localhost:8080/5th/`로 접속하세요.
- Nginx를 실행한 경우 각 단계는 `http://localhost:8080/2nd/`에서 확인할 수 있습니다.

## 예상 결과
ON/OFF 버튼이 보이지만 눌러도 반응하지 않습니다. 아직 JavaScript 이벤트를 만들지 않았기 때문입니다.
