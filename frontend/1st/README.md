# 1단계 — HTML 기본 화면 만들기

## 학습 목표
HTML 문서 구조와 제목·문단·전등 아이콘을 익힙니다.

## 실습 파일
- [index.html](index.html)

## 실행 방법
- 1~4단계: `index.html`을 브라우저에서 직접 열어도 됩니다.
- 5단계: Python Backend와 Nginx를 모두 실행한 다음 `http://localhost:8080/5th/`로 접속하세요.
- Nginx를 실행한 경우 각 단계는 `http://localhost:8080/1st/`에서 확인할 수 있습니다.

## 예상 결과
제목과 💡 아이콘이 표시되지만 버튼은 없습니다.

## 학생 확인 질문
`<h1>`, `<div>`, `<p>`가 각각 무엇을 표시하는지 설명해 보세요.
