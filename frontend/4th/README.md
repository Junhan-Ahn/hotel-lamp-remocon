# 4단계 — 서버 명령용 JSON 만들기

## 학습 목표
Frontend와 Backend가 주고받을 JSON 메시지 형식을 익힙니다.

## 실습 파일
- [index.html](index.html)

## 실행 방법
- 1~4단계: `index.html`을 브라우저에서 직접 열어도 됩니다.
- 5단계: Python Backend와 Nginx를 모두 실행한 다음 `http://localhost:8080/5th/`로 접속하세요.
- Nginx를 실행한 경우 각 단계는 `http://localhost:8080/4th/`에서 확인할 수 있습니다.

## 예상 결과
버튼을 누르면 `{ "type": "set", "on": true }` 또는 `false`가 화면에 표시됩니다. 아직 서버로 보내지는 않습니다.

## 학생 확인 질문
`type`과 `on` 필드의 의미는 무엇인가요?
