# 3단계 — JavaScript로 화면 상태 바꾸기

## 학습 목표
`getElementById`, `addEventListener`, `textContent`, `classList.toggle`을 익힙니다.

## 실습 파일
- [index.html](index.html)

## 실행 방법
- 1~4단계: `index.html`을 브라우저에서 직접 열어도 됩니다.
- 5단계: Python Backend와 Nginx를 모두 실행한 다음 `http://localhost:8080/5th/`로 접속하세요.
- Nginx를 실행한 경우 각 단계는 `http://localhost:8080/3rd/`에서 확인할 수 있습니다.

## 예상 결과
ON/OFF 버튼을 누르면 같은 브라우저에서 전등 상태와 빛 효과가 바뀝니다. 새로고침하면 초기화됩니다.
